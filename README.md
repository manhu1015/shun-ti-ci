# 顺提词

一个纯网页的顺提词，不用下载 App，不用注册，不用登录。

用手机浏览器打开链接就能用：把稿子粘贴进去，选提词屏或摄像头提词，点播放，文字就会按你设定的速度自动滚动。

适合拍口播、短视频、直播口播提词，也适合演讲、汇报、录课时看稿。

支持的浏览器：

- 苹果 iPhone / iPad：Safari
- 安卓手机：Chrome 及主流安卓浏览器
- 鸿蒙手机：鸿蒙浏览器

> 推荐用「添加到主屏幕」的方式使用，点桌面图标就能打开，和 App 一样方便，见下面「使用说明」。

## 功能清单

### 稿件库

- **粘贴整篇稿件**就能新建一篇，不用逐句拆分
- 可以**保存多篇稿件**，每篇显示标题、字数和最后编辑时间
- 稿件可以新建、编辑、删除
- 所有稿件**只存在你自己手机的浏览器里**，不上传到服务器，别人看不到你的稿件

### 两种提词模式

**1. 单独提词屏**

- 全屏大字显示，适合把手机放在相机、提词器支架旁边单独看稿
- 有一条**红色阅读线**，帮你定位当前读到的位置
- 支持**横屏和竖屏**
- 支持**镜像翻转**，配合反射式提词器玻璃使用时文字不会反

**2. 摄像头提词**

- 在工具内直接打开**前置摄像头**
- **半透明提词框**叠在摄像头画面上，边看稿边拍
- 可以**在工具内直接录像**
- **提词文字不会录进视频里**，录出来的只有摄像头画面和声音

### 播放与滚动

- **自动滚动**，点播放开始，点暂停停住
- **滚动速度可调**，播放时也能随时调
- 在提词框内**上下拖动可以手动推稿**，想快进、回看都可以
- **倒计时**：可设为关 / 3 秒 / 5 秒 / 10 秒，**默认 3 秒**，点播放后倒计时结束才开始滚动和录像

### 文字样式

- **字号可调：20–72px**
- **字体可选**：黑体 / 宋体 / 楷体 / 圆体
- **文字颜色可改**
- 设置改完**自动记住**，下次打开不用重新调

### 提词框大小和位置

- 提词框可以**按住顶部拖动**，放到画面上你顺眼的位置
- 在**设置**里可以调提词框大小：
  - **宽度：45%–100%**
  - **高度：15%–60%**（占屏幕高度的比例）
- 调完**自动记住**


### 录像画质

- **手动四档画质**，在拍摄提词页面左上方切换：
  - **4K 30 帧**
  - **1080p 60 帧**
  - **1080p 30 帧**
  - **720p**
- 页面上会显示**实际申请到的分辨率和帧率**，例如「实际 2160×3840 · 30 帧/秒」
- 如果手机或浏览器申请不到你选的那一档，会**自动降到能用的档位**，以页面显示的实际值为准
- **4K 不保证**：能不能录 4K 取决于手机硬件和浏览器支持，见「常见问题」
- **录像中改画质不会立即生效**，要**停止录像后**，下一次录像才按新档位录

### 屏幕常亮

- 进入提词屏或摄像头提词后，会**自动申请屏幕常亮**（Wake Lock），提词过程中屏幕不会自动熄灭
- **退出提词页面后自动释放**，恢复手机原来的熄屏设置
- 页面上会显示「屏幕常亮中」的提示
- 如果浏览器**不支持屏幕常亮**，页面会显示不可用，**设置里会给出替代办法**（例如先把手机系统的自动锁定时间调长）

### 跨平台适配

- 适配**苹果、安卓、鸿蒙**系统
- 字体做了系统回退，鸿蒙设备会优先使用 **HarmonyOS Sans** 等系统字体
- 做了**响应式布局**，宽屏、**折叠屏展开**后页面会自动重新排版，不会挤在一起

### 录制保存

- 录完后，点黄色的**「保存到相册 / 再保存一次」**按钮，才会调起手机的**系统分享面板**
- 在系统分享面板里点**「存储视频」**，视频才会存进相册
- 这是手机系统的限制：**网页不能直接、静默地把视频写进相册**，必须由你点按钮、再在分享面板里确认一次，见「常见问题」

## 使用说明

### 一、三种打开方式

#### 方式 A：直接点链接在浏览器里用（最简单）

1. 在手机上**点开提词器的链接**
2. 页面打开后就能直接用，不用登录

适合临时用一次，或先试试好不好用。

#### 方式 B：添加到主屏幕（推荐，日常使用用这个）

添加到主屏幕后，桌面上会多一个图标，**点图标就像打开 App 一样打开提词器，不用登录，不用每次找链接。**

**iPhone（Safari）：**

1. 用 **Safari** 打开提词器链接
2. 点底部的**「分享」**按钮
3. 在菜单里点**「添加到主屏幕」**
4. 点右上角**「添加」**
5. 回到桌面，**点新出现的图标**就能打开

**安卓（Chrome）：**

1. 用 **Chrome** 打开提词器链接
2. 点右上角**「⋮ 菜单」**
3. 点**「添加到主屏幕」**或**「安装应用」**
4. 按提示点**「添加 / 安装」**
5. 回到桌面，**点新出现的图标**就能打开

**鸿蒙（鸿蒙浏览器）：**

1. 用**鸿蒙浏览器**打开提词器链接
2. 点浏览器**「菜单」**
3. 点**「添加到桌面」**
4. 按提示确认
5. 回到桌面，**点新出现的图标**就能打开

#### 方式 C：下载 index.html 在本地打开（不推荐）

1. 把 **index.html** 文件下载到手机或电脑上
2. 直接点开这个文件用浏览器打开

**不推荐这个方式**：本地打开时，**摄像头调用和录像保存经常不可靠**，不同手机表现也不一样。优先用**方式 A** 或**方式 B**。


### 二、新建一篇稿件

1. 在主页点**「新建稿件」**
2. 填**标题**（不填也能存，方便你自己认稿就行）
3. 把准备好的**整篇稿子粘贴**到正文框里
4. 点**「保存」**
5. 保存后这篇稿件会出现在主页的**稿件库**里，带字数和编辑时间，下次打开还在

### 三、开始提词

1. 在稿件库里**点你要用的那篇稿件**
2. 选一种模式：
   - 点**「提词屏」**：用另一台设备或支架单独看稿
   - 点**「摄像头提词」**：在这台手机上边看稿边拍，第一次使用时浏览器会问是否允许使用摄像头，点**「允许」**
3. 检查一下速度、字号，不合适先在**「设置」**里调好（见下一步）
4. 点**「播放」**按钮
5. 先走**倒计时**（默认 3 秒，可在设置里改成关 / 5 秒 / 10 秒），倒计时结束文字开始自动滚动
6. 读的过程中：
   - 想停：点**「暂停」**
   - 想调速：拖**速度滑杆**
   - 想跳过或回看一段：**在提词框内上下拖动**手动推稿

### 四、调速度、字号和提词框大小

1. 点页面上的**「设置」**（齿轮图标）
2. 按需要调整：
   - **滚动速度**：数字越大滚得越快，先用默认速度试读一遍再微调
   - **字号**：20–72px，离镜头远就调大一点
   - **字体**：黑体 / 宋体 / 楷体 / 圆体，选你读着最顺眼的
   - **文字颜色**：背景亮就用深色字，背景暗就用浅色字
   - **提词框宽度**：45%–100%
   - **提词框高度**：15%–60%
   - **倒计时**：关 / 3 秒 / 5 秒 / 10 秒
   - **镜像翻转**：用反射提词器时打开，普通使用关掉
3. 关掉设置面板即可，**所有设置会自动记住**，不用点保存
4. 提词框的位置不用在设置里调：**按住提词框顶部直接拖**到你想要的位置

### 五、录像和保存到相册（完整步骤）

只在**摄像头提词**模式下录像：

1. 进入**摄像头提词**，确认画面正常，提词框位置和大小合适
2. 在左上方选**画质档位**（4K 30 帧 / 1080p 60 帧 / 1080p 30 帧 / 720p），并看一眼页面显示的**实际分辨率和帧率**
3. 点**「录像」**，走完倒计时后正式开始录，提词会同步滚动
4. 录的过程中**不要切到别的 App**，也不要锁屏
5. 录完点**「停止」**
6. 点黄色的**「保存到相册 / 再保存一次」**按钮
7. 在弹出的**系统分享面板**里点**「存储视频」**
8. 去手机**相册**里确认视频已经存好，再关掉页面

注意：

- 第 6、7 步**缺一不可**。只点停止、不点黄色按钮，视频不会进相册。
- 想再存一份，或上一次分享面板关掉了没存成，再点一次黄色按钮**「再保存一次」**就行。
- 录像中途改画质档位**不会影响正在录的这一条**，停录后下一次才生效。

### 六、屏幕常亮说明

1. 进入提词屏或摄像头提词后，工具会**自动尝试打开屏幕常亮**，页面显示「屏幕常亮中」就是已生效，提词时不用担心屏幕突然变暗、熄灭
2. **退出提词页面就会自动释放**，不用你手动关，手机会恢复原来的自动熄屏时间
3. 如果页面提示**屏幕常亮不可用**，说明当前浏览器不支持 Wake Lock，这时按**设置里的替代办法**操作：先去手机**系统设置**里把**自动锁定 / 熄屏时间调长**（例如调到 5 分钟或永不），再回来提词
4. 长时间常亮会**更耗电**，长时间拍摄前建议插上充电线

## 常见问题

### 从主屏幕点开，为什么跳到 Muse 的登录页面？

这**只发生在 Muse 的分享链接**上：那个链接本身挂在 Muse 的页面下，添加到主屏幕后，系统打开的是 Muse 的入口，所以会先跳登录页。

用独立网址打开时不会这样：独立网址添加到主屏幕后，点图标直接打开提词器，不用登录任何账号。

### 为什么录完像还要多点一下才能保存？

因为**手机系统不允许网页直接把视频静默写进相册**。网页能做的只有调起**系统分享面板**，由你本人在面板里点**「存储视频」**确认保存。

所以流程固定是两步：点黄色**「保存到相册 / 再保存一次」** → 在分享面板里点**「存储视频」**。任何网页提词工具都绕不开这一步，不是这个工具多加的步骤。

### 为什么选了 4K，录出来不是 4K？

网页能申请的画质受**手机硬件、摄像头能力和浏览器支持**三方面限制，申请不到时浏览器会给一个能用的较低档位。所以：

- **4K 30 帧只是申请目标，不保证一定能录到**
- 以拍摄页面上显示的**「实际分辨率和帧率」**为准，那才是这一条真正录制的画质
- 对画质要求稳妥时，直接选 **1080p 30 帧**，大多数手机都能稳定录到

### 鸿蒙和折叠屏为什么说要真机再验？

页面已经按网页标准做了鸿蒙适配（包括 HarmonyOS Sans 字体回退）和宽屏 / 折叠屏的响应式布局，但不同品牌、不同系统版本的浏览器细节有差异，**模拟环境验不全**。

如果你在鸿蒙手机或折叠屏上遇到字体、布局、屏幕常亮或摄像头的问题，请以**真机实际显示**为准，并把手机型号、系统和浏览器版本一起反馈给开发者，方便定位。

### 为什么换个浏览器，我的稿件就没了？

稿件存在**当前浏览器的本地存储**里，和浏览器绑定：

- 在 Safari 里存的稿件，在 Chrome 里看不到，反过来也一样
- 在浏览器里打开和添加到主屏幕打开，如果用的不是同一个浏览器，数据也不互通
- 清除浏览器数据、卸载浏览器，稿件也会被清掉

解决办法：**固定用同一个浏览器打开**（推荐固定用添加到主屏幕的那个图标），重要稿件在别处**自己备份一份原文**。

### 屏幕常亮已经开了，为什么屏幕还是会暗？

先确认页面上显示的是**「屏幕常亮中」**。如果显示不可用，说明当前浏览器不支持 Wake Lock，按设置里的替代办法，先把手机**系统自动锁定时间调长**再使用。另外，从提词页面切到别的 App 再切回来，常亮可能会被系统释放，回到提词页面后它会重新申请，稍等一下看提示恢复即可。

### 摄像头提词打开后没有画面怎么办？

1. 确认浏览器弹窗询问摄像头权限时你点了**「允许」**；如果之前点过拒绝，去浏览器和手机系统的**权限设置**里把这个站点的摄像头权限重新打开
2. 确认没有别的 App 正在占用摄像头
3. 不要用本地打开 index.html 的方式（方式 C），改用**链接打开**（方式 A / B）再试
